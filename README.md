# Booking App

Aplicación de reservas de hotel desarrollada con Flutter como proyecto de aprendizaje. Se inspira en el [tutorial de Shivam Gupta](https://www.youtube.com/watch?v=04k2G18ozPw); este repositorio contiene el trabajo realizado de forma independiente.

## Estado actual

- Proyecto Flutter creado para Android, iOS, web y escritorio.
- Pantalla inicial en `lib/pages/home.dart` con una imagen local.
- La app aún está en desarrollo; reservas, autenticación y pagos no están implementados.

## Requisitos

- Flutter SDK y Dart.
- Un emulador Android o un dispositivo compatible.

## Ejecutar

```sh
flutter pub get
flutter run
```

Las imágenes locales se guardan en `images/` y se registran en `pubspec.yaml`.
